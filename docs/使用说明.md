# 酷态科 10 号充电器 · 电脑常驻控制台

在 Windows 上通过蓝牙（BLE）直连控制充电器，不经过米家云，也不需要 root。

设备：CUKTECH 10 GaN Charger Ultra（`njcuk.fitting.ad1204`，固件 2.1.2_0073）  
地址：<http://127.0.0.1:8080>

> 这份文档分三部分：**第一部分**照着做就能装上并连上设备；  
> **第二部分**逐个说明功能怎么用；**第三部分**是遇到问题时的排查清单。

---

# 第一部分：装上就能用

## 1. 电脑需要什么

| 条件 | 说明 |
| --- | --- |
| Windows 10 / 11，64 位 | 程序自带运行环境，**不用装 Python**，也不需要管理员权限 |
| 微软 **WebView2 运行时** | Win11 和打过 Edge 更新的 Win10 都自带。真缺了，启动时会弹中文提示并给官方下载链接，不会静默失败 |
| 蓝牙 | 笔记本自带即可；台式机需要蓝牙适配器，否则只能看历史数据、连不上设备 |
| 自己的米家账号 | 二维码登录的是**扫码人自己的小米账号**，且账号下已绑定这台充电器 |

## 2. 装

双击 `CUKTECH-Setup_v2.0.0.exe`，勾选需要的东西，点安装。全程不弹管理员权限提示。

- 程序装到 `%LOCALAPPDATA%\Programs\CUKTECH`
- 数据（配置、历史功率、日志）放 `%LOCALAPPDATA%\CUKTECH`，卸载时可以选择保留
- 程序目录里的 **`版本更新说明.md`** 记着这一版改了什么，想知道多了哪些功能直接双击看
- 卸载：开始菜单 → CUKTECH → 卸载，或 Windows「设置 → 应用 → 已安装的应用」

> **第一次双击可能弹「Windows 已保护你的电脑」**：安装包没有代码签名，点
> 「更多信息」→「仍要运行」即可。这一步会卡住很多人，提前说一声。

装完**默认开机自启**（写在当前用户的启动项里，不需要管理员权限），
不想要就在「运行管理」里关掉。

## 3. 第一次打开：扫码连上设备

装完第一次启动，会先弹一个「连接充电器」窗口，中间是一张登录二维码：

1. 手机打开 **米家 App**，点右上角「扫一扫」
2. 扫窗口里的二维码，扫完**在手机上点「确认登录」**（不点会超时）
3. 窗口自动识别出 MAC / TOKEN / BLE KEY 并写成配置，然后自己关掉，控制台直接连上

全程不用手抄、不用命令行、不用点保存。凭据只写到本机 `%LOCALAPPDATA%\CUKTECH\.env`，
不会上传到任何地方。

- **二维码过期前会自动换新的**：窗口上会提示「二维码已刷新」，什么时候扫都有一张有效的码
- **取码程序崩了会自己重来**：连续失败 6 次才停下，并在窗口底部提示可以手动填写
- 扫码不成功时，窗口最下面有「扫码不成功？手动填写」，可以粘贴三项或从文件导入

> 已经配置过的机器再打开这个窗口不会自动扫码，只显示当前 MAC 和一个「重新扫码」按钮。  
> 想再打开它：托盘右键 →「设置设备凭据…」。

## 4. 日常怎么用

扫码连上之后，日常你只会看到两样东西：**托盘图标** 和 **桌面上的小卡片**。

| 想做什么 | 怎么做 |
| --- | --- |
| 打开内部控制台 | 双击桌面/开始菜单图标，或点托盘图标 |
| 打开运行管理（四个开关） | 控制台窗口右下角「⚙ 运行管理」，或托盘右键 → 运行管理… |
| 把窗口收起来 | 点窗口的 X —— 收进托盘，**程序继续在后台跑** |
| 启停采集服务 | 运行管理里的「采集服务」开关，或托盘右键 |
| 启停桌面卡片 | 运行管理里的「桌面卡片」开关（关掉可省内存） |
| 托盘要不要显示瓦数 | 运行管理里的「托盘功率」开关（关掉图标退回纯闪电） |
| 开关开机自启 | 运行管理里的「开机自启」开关，或托盘右键 |
| 看当前功率 | 鼠标悬停托盘图标（或看图标上的数字，前提是「托盘功率」开着） |
| 把卡片钉在固定位置 | 卡片右下角**图钉**点一下；再点解除（详见「桌面卡片」） |
| 彻底退出 | 托盘右键 → 退出 |

**它不依赖浏览器**：采集服务是本地后台进程，控制台是程序自己的窗口，
**所有操作都在这个窗口里完成**，关掉浏览器完全不影响。

## 5. 几件必须知道的事

1. **手机米家会显示离线**。充电器只接受一条蓝牙连接，电脑连着，手机就连不上；
   你打开米家，电脑端就会断（15 秒内自动重连回来）。
2. **电脑睡眠 = 断链**。电脑进入睡眠后连接会断开，唤醒后自动重连。
   要真正 7×24 常在，自己在 Windows 电源设置里把睡眠改成「从不」——程序不会替你改电源计划。
3. **不要在多台设备上同时连**。米家、这个控制台、别的脚本，同一时刻只能有一个。
4. **不要把 `%LOCALAPPDATA%\CUKTECH\.env` 发给别人**。里面是这台机器 + 这个米家账号
   专属的凭据；对方要用自己的账号扫自己的码。
5. **凭据是设备专属的**。换充电器、在米家里重新绑定设备都会换凭据，
   需要重新扫码（托盘右键 →「设置设备凭据…」）。

# 第二部分：功能说明

## 内部控制台

完整控制界面就在程序自己的窗口里：**同一个页面、同一个源，只是不用离开应用**，
不会中途跳到浏览器里去。

### 怎么用

| 入口 | 结果 |
| --- | --- |
| 双击桌面 / 开始菜单图标 | 直接打开内部控制台（主窗口，1160×820，可最大化） |
| 托盘图标双击 / 右键 → 控制台 | 同上；已打开时是「显示/隐藏」开关 |
| 托盘右键 → 运行管理 | 亮出控制台窗口并展开右下角「运行管理」浮层（服务 / 卡片 / 托盘功率 / 开机自启四个开关，外加版本更新、捐赠、问题反馈邮箱） |
| 桌面卡片点「完整面板 ↗」或双击卡片 | 拉起内部控制台 |
| 托盘右键 → 重新加载控制台 | 窗口白屏 / 页面卡住时强制重新载入（采集服务不动，只在窗口里重开一次页面） |

### 窗口里有什么

- **总功率能量条**：顶部实时流动条 + 数值，随功率变色
- **四口实时数据**：C1 / C2 / C3 / A 各自的功率、电压 / 电流、功率条
- **端口开关**：每口一个开关，点一下立刻生效并回报结果（带 toast 提示）
- **倒计时**：每口 15 / 30 / 60 分钟快捷按钮 + 自定义分钟数
- **设备设置**：场景模式（AI / 数码生态 / 单口 / 均衡）、息屏时间、语言、USB-A 小电流常开、
  空闲息屏、屏幕方向锁 —— 全部分段按钮 / 开关，点完立刻生效
- **连接控制**：连接设备 / 断开、右上角刷新（重读设备设置）
- **历史曲线**：日期 / 端口 / 粒度 三项切换；默认「今天 + 按分钟」，同一张图里叠两条线 ——
  所选端口的**功率**（绿）和全场**总功率**（蓝），看图就知道这一口占了总功率多少。
  图表资源随程序打包，**断网也能画**
- **实时同步**：设备状态变化 0.5 秒内推到界面；断开时顶部弹「连接已断开，正在重连…」，
  恢复后自动接上

**能读**：四个端口（C1/C2/C3/A）各自的电压、电流、功率、当前协商协议；总功率；历史曲线。  
**能改**：场景模式、每个端口独立开关、逐口协议开关（PD / PPS / UFCS / SCP）、每口倒计时、
USB-A 小电流常开、息屏时间、语言、空闲息屏、屏幕方向锁。  
**做不到**：指定 PD 输出电压电流档位。协商是充电器和被充设备之间的事，软件只能开关某类协议。

- 四个开关：**采集服务**（关掉后所有控制失效）、**桌面卡片**、**托盘功率**、**开机自启**
- 一行 **版本更新**：显示当前版本，有新版本时出现「立即更新」按钮（见下一节）
- 一行 **支持开发**：右侧「捐赠」按钮，点开是收款码浮窗（微信 / 支付宝两个页签）
- 一行 **问题反馈**：显示 `X3093354438@icloud.com`，点文字或右侧「复制」进剪贴板
- 两个按钮：**数据目录**（资源管理器打开）、**退出**（整个程序退出）

捐赠浮窗页脚也放了同一个邮箱（点一下直接写邮件，标题已填「CUKTECH 问题反馈」）。

浮层是**注入到页面里的**，不是第二个窗口——所以它跟着页面一起加载、跟着页面一起消失，
不存在「窗口在、页面死」这种半残状态。

用**普通浏览器**打开 `http://127.0.0.1:8080` 时不会有这个按钮（那边没有程序接口，
按了也没用），看到的就是干净的控制页面。

### 检查更新

程序会自己看有没有新版本，**不需要手动去问**。

- **什么时候查**：启动后约 40 秒查一次，之后 24 小时内不再查（避免每次开程序都打网络）。
  想立刻查，点浮层里的「检查」或托盘右键的「检查更新…」。
- **在哪看**：浮层里的「版本更新」一行，托盘菜单里也会显示成 `↑ 有新版本…`。
- **怎么装**：点「立即更新」→ 自动下载（有进度条）→ 校验安装包 → 程序自己关掉 → 静默装好 → 自动重新打开。
  手动改过的设置、取好的凭据、历史功率数据都保留。

几条设计上的取舍，遇到问题先看这里：

| 情况 | 表现 |
| --- | --- |
| 没网 / 清单打不开 | **什么都不弹**，只往 `logs\manager.log` 记一行，下次再试 |
| 安装包校验失败 | 删掉包、提示「校验失败」，**不会安装**；程序照常用 |
| 磁盘空间不够 | 下载前就拦住，提示需要多少空间 |
| 更新失败 | 安装包留着，浮层里点「重试」；也可去 Releases 页手动下载 |
| 你关掉了开机自启 | 更新**不会**把它重新打开 |
| 你删了桌面快捷方式 | 更新**不会**把它重新建出来 |

### 自动启动

早上开机后经常发现有几个口是关着的（前晚手动关过、或设备记着上次的状态），  
这个功能就是补这一步：**在所设范围内，只要有一个口是关的，就把它打开**；已经开着的不用管。

**在哪设**：控制台页面 → **设备设置** 卡片 → **场景设置** 分组里的「自动启动」。  
和「场景模式」并排成一条列表项，右侧是开关；打开后开关下面才会展开时间窗和端口范围。  
改完立即生效、立即存盘，没有额外的保存按钮。

| 选择框 | 可选值 | 说明 |
| --- | --- | --- |
| **时间窗** | 任意 `HH:MM – HH:MM`（默认 `07:00–12:00`） | 只有在这个时段内启动程序才会检查。结束时间按**整分钟含进去** |
| **端口** | **全部充电口** / **C1** / **C2** / **C3** / **A** | 五种互斥，选哪个就只动哪个；其余口即使是关的也不碰 |

**端口范围怎么影响行为**

| 模式 | 检查范围 | 会动的口 | 「今天做过了」的判据 |
| --- | --- | --- | --- |
| 全部充电口 | C1 / C2 / C3 / A | 四个口里没开的全部打开 | 复核到四口全开才占名额 |
| 单个端口（如 C3） | 只看 C3 | **只开 C3**，另外三个口即使关着也不碰 | 复核到 C3 已开就占名额 |

单口模式下别的口关着不算失败——本来就不该碰它们，复核也只看所选的那个口。

**什么时候会触发（只在程序启动时判断一次，不是定时器）**

| 条件 | 说明 |
| --- | --- |
| 开关 | 设备设置 → 场景设置里的 **自动启动** 开关（默认开着）。关掉后启动时完全不检查 |
| 时机 | **程序启动时**判断一次（含开机自启）。不是整点触发，也不轮询 |
| 时间 | 启动那一刻必须落在**所设时间窗**内，否则只写一行日志、什么都不做 |
| 设备 | 采集服务要先连上充电器（最多等 3 分钟）；连不上就记一条「本次未执行」 |
| 当天 | 当天**已经真的开过口**就不再重复（反复重启不会重复发蓝牙命令） |

**怎样才算「今天已经做过了」**

不是「连上设备、检查过就算」，而是**本次真的开过口**才算：

| 启动时的实际情况 | 是否占用当天名额 |
| --- | --- |
| 所选端口本来就全开，一个命令都没发 | **不占**——当天再启动还会再查一次 |
| 有未开的口，本次补开并复核到所选端口全开 | 占用——当天不再自动跑 |
| 没连上设备 / 读不到状态 / 补开失败 | 不占——当天重启会重试 |

这样「早上检查时恰好全开、下午你手动关了一个」就不会被漏掉：当天再启动程序它会自己补开。  
代价是端口长期全开时每次启动多读一次状态（几十毫秒），这个取舍是故意的。

**时间边界**：`开始时间 ≤ 现在 < 结束时间 + 1 分钟`

- **含开始**：`07:00` 起就能触发；
- **含结束整分钟**：默认的 `12:00` 表示 12:00:00–12:00:59 期间启动仍然触发，12:01:00 起不再触发。
- 开始时间等于结束时间 = 只在那一个整分钟内生效；
- 开始时间晚于结束时间会被拒绝（页面上会弹提示，不会存进去）；
- 时间窗之前启动不触发——按设计「只在启动时判断」，不会到了点再补做。

**它只看每个口有没有被打开**，跟「有没有在充电」是两件事：没插设备的空口也可能被打开，
而关掉的口不管插没插东西都算关着。

**执行过程**

1. 起点校验：时间窗 → 当天是否已经「开过口」；
2. 等采集服务连上充电器（自动触发时，等待期间出了时间窗就放弃）；
3. 从设备重新读一遍四个口的开关状态（不用缓存，避免把已开的看成关的）；
4. 在**所选范围**内算出没开的端口；全开则直接结束，一个命令都不发，**也不占当天名额**；
5. 对没开的端口逐个打开，已开启的完全不动；
6. 再读一遍复核，**所选端口全开**才记下当天已完成；没全开则记一条错误，下次启动重试。

日志（`%LOCALAPPDATA%\CUKTECH\logs\manager.log`）：

```
[自动开端口] 触发：07:12:31（窗口 07:00–12:00，含两端；范围 全部充电口）
[自动开端口] 全部充电口 内未开启：C3，开始逐个开启
[自动开端口] C3 已开启
[自动开端口] 今日 07:12:34 自动检查：C3 未开 → 已全部开启，复核 全部充电口 全开
```

没触发时只有一行：`[自动开端口] 不在 07:00–12:00 时段（现在 13:02:11），本次不执行`。  
所选端口本来就全开时多一句「无需处理，不占今日名额」。

- **开关**：默认开。关掉后启动时不再检查，手动「立即」仍可用（那是你明确点的）。
- **「立即」按钮**：手动强制检查一次，忽略时间窗和「当天已开过口」的限制，用来补做或验证。

### 服务没起来的时候

窗口不会白屏，会显示一个引导页：闪电图标 + 三步进度（启动采集服务 → 等待本地接口 → 载入界面），
超时或失败时给出「重试 / 重启采集服务 / 运行管理」三个按钮。

## 桌面卡片

一块 324×216 的深色圆角小卡片，常驻桌面：

- **固定在桌面**（默认，说的是层级，和下面「固定位置」锁坐标是两件事）：卡片是**桌面窗口的子窗口**，和壁纸、桌面图标、桌面整理软件的格子处在同一层。看着桌面时它在，一开浏览器/文档就被盖住，不挡事；按 `Win+D` 显示桌面**它不会消失**
- **拖动**：按住顶部「CUKTECH 10 Ultra」那一行拖走，松手位置自动记住
- **固定位置**：点右下角那枚**图钉**，卡片就钉在当前坐标——顶部拖动区立刻失效，别人（或系统）把它挪走，**1~2 秒内自动弹回原位**；图钉变青色＝已固定，再点一下解除。状态会记住，**重启、重新登录、切显示方式都还钉着**
- **点端口**：点 C1 / C2 / C3 / A 任意一格，直接开关该端口
- **切模式**：底部四个胶囊（AI / 数码 / 单口 / 均衡）点一下即切换
- **收起**：点右下角 `✕` 收进托盘；托盘闪电图标单击可再弹出
- **完整面板**：点「完整面板 ↗」或双击卡片空白处，拉起内部控制台窗口
- **不占任务栏**：卡片是桌面挂件，任务栏和 Alt+Tab 里都不会出现它
- **托盘**：图标随功率变色（青 → 黄 → 橙），鼠标悬停显示当前总功率，右键可开关端口、切模式、**切换显示方式**、退出

### 显示方式（托盘右键 → 显示方式）

| 方式 | 效果 |
| --- | --- |
| **固定在桌面** | 桌面层子窗口：和桌面图标同层，所有应用窗口之下。不挡事，`Win+D` 也不消失。想随时看功率就选它 |
| **悬浮置顶** | 永远压在最上层，盖住别的窗口。适合边充边盯功率 |

选过一次会记住，下次启动沿用。

卡片和后台服务是两个独立进程：卡片关掉不影响采集，服务挂了卡片会显示「控制台未响应」
并在恢复后自己接上。卡片占用内存很少（几十 MB 量级）。

# 第三部分：常见问题与排障

## 常见问题

**托盘里找不到图标？** 点任务栏 `^` 展开隐藏图标，把闪电拖到常显区。

**双击图标没反应？** 说明已经有一个在跑 —— 它会把你已有实例的面板叫到前面（单实例互斥）。

**双击后什么都没发生，连错误框都没有？** 最可能是系统缺 WebView2 运行时。
程序会自动弹出中文提示并给下载链接，照提示装一下即可。

**卡片跑哪去了？** 它是「固定在桌面」模式：按 `Win+D` 显示桌面就能看到。  
想让它一直浮在最上面，托盘右键 → 显示方式 → 悬浮置顶。

**卡片上写着「控制台未响应」？** 表示本地服务没跑起来，卡片退回了本地页面。  
直接运行 `%LOCALAPPDATA%\Programs\CUKTECH\CUKTECH.exe`（或开始菜单里的 CUKTECH），2 秒内自动恢复。

**控制台窗口一片纯黑，但卡片上数据是好的？** 是内嵌浏览器控件没建起来。
程序会自动重试，必要时自动重启并给出提示；仍不行就托盘右键退出后重新打开。
日志在 `logs\webview.log`。

**手机米家一直离线？** 正常。充电器只有一条蓝牙连接，电脑连着手机就连不上。

**想在浏览器里看？** 在电脑浏览器打开 `http://127.0.0.1:8080`，功能和窗口里一样，
只是没有右下角的「运行管理」按钮。

## 排障

| 现象 | 原因 / 处理 |
| --- | --- |
| 网页打不开 | 托盘右键退出后重新打开程序；或看 `logs\console.log` |
| 状态一直 DISCONNECTED | 手机米家还占着连接；或充电器被拔了电源。日志里会打印每次重试的失败原因 |
| 日志提示「找不到设备」（`Device with address … was not found`） | 充电器没通电 / 别的设备连着 / 地址变了 / 蓝牙适配器没开，见下一段 |
| 扫描扫不到设备 | 断电 10 秒再插回（部分固件断开后停止广播） |
| 认证失败 | 凭据变了。在米家里重新绑定设备会换凭据，托盘右键「设置设备凭据」重新扫码 |
| 连上但读不到端口数据 | 端口上没插设备时本来就是空的，正常 |
| 卡片一片空白 / 白框 | 系统缺 WebView2 运行时（启动时会提前拦住并提示） |
| 卡片显示「控制台未响应」 | 后台服务没起。打开控制台程序即可，卡片会自己恢复 |
| 卡片拖不动 | 只能按住顶部标题那一行拖（其余区域留给点端口和切模式） |

日志：`%LOCALAPPDATA%\CUKTECH\logs\` 下的 `manager.log` / `console.log` / `widget.log`。

### 提示「找不到设备」怎么办

这句话会在四种完全不同的情况下出现，按顺序试就行：

| 实际情况 | 怎么判断 | 怎么处理 |
| --- | --- | --- |
| 充电器没通电 / 待机后不再广播 | 日志里能扫到别的蓝牙设备，但没有这台 | 给充电器通电，插个负载唤醒，再重启采集服务 |
| 已被别的主机连着（手机米家、另一个脚本） | 同上：被占用时通常不广播 | 关掉手机米家，等 15 秒自动重连 |
| 配置里的地址过期（设备换了地址） | 能扫到名字带 `njcuk` 的设备，但地址对不上 | 托盘右键「设置设备凭据」重新扫码 |
| 蓝牙适配器关了 / 驱动异常 | 一台都扫不到 | 先查系统蓝牙开关和驱动 |

连接失败时程序会自动做一次扫描，把结论写进 `logs\console.log`（附近有几台蓝牙设备、
有没有目标设备），照着日志里那句「结论」处理最快。

## 程序和数据放在哪

| 内容 | 路径 |
| --- | --- |
| 程序 | `%LOCALAPPDATA%\Programs\CUKTECH` |
| 数据 / 日志 | `%LOCALAPPDATA%\CUKTECH` |
| 凭据 | `%LOCALAPPDATA%\CUKTECH\.env`（**含凭据，不要外发**） |
| 开机自启 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\CUKTECH` |
| 卸载信息 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\CUKTECH` |
| 安装/卸载日志 | `%TEMP%\cuktech-setup.log` |

卸载时数据默认保留（界面上勾选才会删），重装后历史功率还能接着看。

服务一启动就连设备并完成认证（约 4 秒），断线后 15 秒内自动重连。
安装包里不带任何凭据，可以放心发给别人。
